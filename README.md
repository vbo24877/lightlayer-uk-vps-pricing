## “不限流量”和“不限速度”要分开看

三档方案都写 Unlimited data，同时各自标了端口速率：Startup 100Mbps，另外两档 200Mbps 起。这两件事不冲突，但含义不同。

不限流量指不按 GB 计费、不设月流量上限；端口速率决定你任何时刻能跑多快。100Mbps 端口跑满一天理论上约 1TB 出头，一个月能到 30TB 量级，对个人项目足够，对跑大流量分发就不够看。英国区测评口径是 300Mbps 端口配 1T 至 10T 月流量。选购时不要只看“不限流量”，要看流量是否封顶、端口多大。

**英国机房和香港、洛杉矶机房比贵多少？**

**1 核 1G 够干什么？**

跑一个 WireGuard 或 OpenVPN 端点、做广告落地页验证、挂个小博客、当 API 中转，够用。跑 Windows、跑 Docker 里几个容器、跑数据库，不够。Startup 不能升级，选它之前想清楚。

**能装 Windows 吗？**

官网 FAQ 说需要时提供 Windows 系统，没有写明授权是否额外收费，也没写哪些套餐支持。按行业惯例 1G 内存的档位跑不动 Windows，实际要从 2G 起。

**支持 IPv6 吗？**

2024 年的测评记录是那台测试机没有分配 IPv6。现在是否默认提供，公开页面没有明确说明，需要问客服。

**多久能开通？**

公开页面没有写部署时间。第三方测评的描述是下单后自动开通，具体时长没有官方数字。
